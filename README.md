# Traffic sign ML model evaluation pipeline

The repo contains a pipeline to systematically generate the attacks on traffic signs and evaluate the performance of the various Deep Learning models developed for CARAMEL project. 

- Attack types
  - [x] Various level of noise attacks (high and low intensity) 
  - [x] Various pattern attacks (big and small)
